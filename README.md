# Salla Docs Skill

Agent skill providing comprehensive [Salla](https://salla.dev) e-commerce platform documentation.

## Install

```bash
npx skills add inomaa/salla-docs
```

## What's included

- **Merchant API** -- Products, orders, customers, shipping, payments, coupons, taxes, webhooks, and 50+ endpoint groups
- **Storefront SDK** -- JavaScript modules for auth, cart, product, currency, events, forms, ratings, wishlists
- **Twilight Theme Engine** -- Twig-based layouts, pages, components, file structure
- **App Development** -- OAuth, app functions, CLI commands, review process

149 consolidated reference files covering 676 source documentation pages.

## Compatibility

Works with Claude Code, Cursor, Windsurf, and other AI agents that support the agent skills standard.
